# CertCoach — چک‌لیست SEO خارج از کد (قدم‌به‌قدم)

این‌ها کارهایی هستن که من (Claude) نمی‌تونم انجام بدم چون نیاز به حساب کاربری شخصی/برندی خودت دارن. کد سمت من آماده‌ست (robots.txt, sitemap.xml, Schema.org, Metadata) — این چک‌لیست فقط قدم‌های بعدیه.

---

## ۱. Google Search Console (مهم‌ترین قدم)

1. برو به: https://search.google.com/search-console
2. با همون ایمیلی که برای certcoach.de استفاده می‌کنی وارد شو
3. «Add Property» بزن → «Domain» رو انتخاب کن → بنویس: `certcoach.de`
4. گوگل یک رکورد DNS (TXT) بهت می‌ده — باید بری توی پنل مدیریت دامنه‌ات (جایی که دامنه رو خریدی، مثلاً IONOS, Strato, GoDaddy) و اون رکورد رو اضافه کنی
5. بعد از تأیید (ممکنه چند ساعت طول بکشه)، برو به بخش **Sitemaps** (سمت چپ) → بنویس: `sitemap.xml` → Submit
6. بخش **URL Inspection** رو برای صفحه‌ی اصلی هم بزن → «Request Indexing» رو بزن (این به گوگل می‌گه «همین الان بیا این صفحه رو بخون»)

## ۲. Bing Webmaster Tools

1. برو به: https://www.bing.com/webmasters
2. با اکانت مایکروسافت وارد شو
3. **نکته‌ی خوب:** Bing یک دکمه‌ی «Import from Google Search Console» داره — اگه قدم ۱ رو انجام داده باشی، همه‌چیز خودکار وارد می‌شه، لازم نیست دوباره از صفر انجام بدی
4. اگه نخواستی این‌طوری، همون کار قدم ۱ رو برای Bing هم تکرار کن (Domain رو اضافه کن، DNS رو تأیید کن، Sitemap رو Submit کن)

## ۳. پروفایل‌های شبکه‌های اجتماعی (Backlink و اعتبار برند)

برای هرکدوم، دقیقاً از اسم **CertCoach** استفاده کن و لینک `https://www.certcoach.de` رو توی بخش «Website» پروفایل بذار:

- [ ] LinkedIn — یک صفحه‌ی شرکتی (Company Page) بساز، نه فقط پروفایل شخصی
- [ ] GitHub — اگه بخشی از کد رو عمومی می‌کنی (اختیاری)
- [ ] YouTube — حتی یک کانال خالی با لینک سایت کمک می‌کنه
- [ ] Instagram / X (Twitter) — اختیاری ولی مفید

## ۴. Google Analytics (آمار واقعی بازدیدکننده)

1. برو به: https://analytics.google.com
2. «Start measuring» → اسم پراپرتی: CertCoach → URL: certcoach.de
3. یک کد ردیابی (Measurement ID مثل `G-XXXXXXX`) بهت می‌ده
4. این کد رو برام بفرست تا توی سایت وصلش کنم (این بخشش با منه)

**نکته:** سایت الان از Vercel Analytics استفاده می‌کنه که آمار پایه رو نشون می‌ده، ولی Google Analytics جزئیات بیشتری داره (منبع ترافیک، کلمات کلیدی، مسیر کاربر).

## ۵. محتوا (بزرگ‌ترین عامل موفقیت بلندمدت)

گوگل سایت‌های «زنده» و پرمحتوا رو بیشتر نشون می‌ده. هر هفته حتی یک مطلب کوتاه:
- «چطور AZ-900 رو در ۲ هفته قبول شویم»
- «بهترین گواهینامه‌های IT در آلمان ۲۰۲۶»
- مقایسه‌ی گواهینامه‌ها

می‌تونی متن خام بفرستی، من کمکت می‌کنم ویرایش و برای سایت آماده‌ش کنم.
